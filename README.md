# Tree Growth Stimulator 🌱

A basic web-based Tree Growth and Agriculture Chemical Effect Simulator built using HTML, CSS, and JavaScript.

## Features

* Water the plant
* Add Urea for plant growth
* Add Potassium Nitrate (KNO₃) for flowering
* Add Potassium Sulphate (SOP) for fruit development
* View the effect of a pesticide on the plant

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Objective

This project demonstrates how different fertilizers and pesticides can affect plant growth. It is a basic prototype created for learning web development and agricultural concepts.
